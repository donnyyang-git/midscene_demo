你是一個資深的自動化測試工程師，請為 Playwright + Midscene.js 撰寫一個自動化測試腳本。
目標是前往「台塑網採購公報頁面」進行特定案號的查詢，並以結構化表格輸出結果。

請依據以下結構與步驟生成完整的 TypeScript 測試程式碼（包含 dotenv 與完整的環境設定）：

---

### 1. 測試基礎設定
- 逾時時間 (Timeout)：設定為 360000 毫秒。
- 目標網址：https://www.e-fpg.com.tw/j2sp/prc/prc_anno_gst_srh.jsp?lang=Big5
- 初始化：需啟用 Midscene 的 PlaywrightAgent。

### 2. UI 定位與容錯點擊策略（核心 AI 操作提示詞）
- 🔍 aiLocate 目標描述：定位「『詢價案號:』後方的輸入框」。
- ⚠️ 容錯機制：
  - 由於底層大語言模型（如 Qwen3.5）可能會將點擊點落入輸入框的右下角框外，請在程式碼中獲取中心點座標後，將 Y 軸向上微調 20 像素 (y - 20) 再執行 `page.mouse.click`。
  - 同時提供備用方案（備份提示詞）：如果座標定位失敗，直接使用單行 ai 命令：「在『詢價案號:』右側的輸入框輸入 '01-2E0AC3'」。

### 3. 表單互動流程
- 操作輸入：在該輸入框內輸入詢價案號 "01-2E0AC3"。
- 鍵盤導覽：為確保觸發送出，輸入後按下鍵盤的 `Tab` 鍵將焦點移至下一個控制項（即開始查詢按鈕），隨即按下 `Enter` 鍵觸發查詢。
- 頁面等待：觸發後等待 4 秒以確保資料完全載入。

### 4. 結構化資料擷取 (aiQuery 提示詞)
請使用 `agent.aiQuery` 來擷取查詢結果。請嚴格依據以下 Schema 進行資料轉換：
- 輸出格式定義：
  Array<{ 
    詢價案號: string, 
    採購名稱: string, 
    申購公司: string, 
    交貨地: string, 
    數量和單位: string, 
    截標日期: string, 
    狀態: string 
  }>
- 擷取指示：
  「提取查詢結果表格中的所有案件列表。包含詢價案號、採購名稱、申購公司/事業部、交貨地、數量和單位、截標時間與狀態。若無資料則回傳空陣列 []。」

### 5. 後續輸出
- 使用 `console.table` 將擷取到的結構化陣列格式化印出至終端機。
- 若無資料或非陣列，則直接以 `console.log` 印出原始結果。
